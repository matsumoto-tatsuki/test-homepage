# TAKUMI YAMATO - Official Portfolio Site

ボディメイクトレーナー大和拓海の公式サイト（ポートフォリオ）です。
「ストーリー共感型」をコンセプトに、トレーナーの人柄や過去の経験（挫折と克服）を通じて、ユーザーとの信頼関係を築くことを目的としたWebサイトです。

## ✨ コンセプト & デザイン

- **Concept**: 「変われる。あなたも、何度でも。」
    - 才能や実績を誇示するのではなく、等身大のストーリーで「私も変われるかも」という希望を届けます。
- **Design Theme**: Natural & Honest（ナチュラル・誠実）
    - 白とオフホワイトを基調に、落ち着いたブルー（#5a8ab8）をアクセントに使用。
    - 余白を多めに取り、読み物として心地よい縦スクロール構成。
    - フォントは明朝体（Noto Serif JP）とゴシック体（Zen Kaku Gothic New）を組み合わせ、誠実さと親しみやすさを両立。

## 🚀 閲覧方法

このフォルダ内の `index.html` をブラウザ（Chrome, Edge, Safariなど）で直接開いてください。
静的なHTML/CSS/JS構成のため、サーバーやビルドツールは不要です。

## 📁 ディレクトリ構成

```
.
├── index.html        # メインHTMLファイル
├── style.css         # スタイルシート（ナチュラル・ブルー基調）
├── main.js           # スクリプト（フェードインアニメーション等）
├── README.md         # プロジェクト説明書
└── *.webp            # 画像アセット（配置用）
```

## 🎨 画像のカスタマイズ

以下のファイル名で画像をプロジェクトルートに配置すると、自動的にサイトに反映されます。
（現在はプレースホルダーが表示されています）

1. **`hero_portrait.webp`**:
   - ヒーローセクション用。
   - 推奨: 自然光の中で撮影された、明るい笑顔の写真やトレーニング風景。
2. **`story_before_after.webp`**:
   - ストーリーセクション用。
   - 推奨: 過去の自分と現在の自分を比較する画像、または象徴的なエピソード画像。
3. **`profile_casual.webp`**:
   - プロフィールセクション用。
   - 推奨: ジャージや私服など、人柄が伝わるカジュアルな写真。

## 🛠 技術スタック

- **HTML5**: セマンティックなマークアップ
- **CSS3**: 変数管理、Flexbox/Gridレイアウト、レスポンシブ対応
- **JavaScript**: Intersection Observer API によるスクロール検知
- **Google Fonts**: Noto Serif JP, Zen Kaku Gothic New

## 📄 ライセンス

このプロジェクトはポートフォリオとして自由に使用・改変可能です。
