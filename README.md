# TAKUMI YAMATO - Official Portfolio Site

ボディメイクトレーナー大和拓海の公式サイト（ポートフォリオ）です。
「ストーリー共感型」をコンセプトに、トレーナーの人柄や過去の経験（挫折と克服）を通じて、ユーザーとの信頼関係を築くことを目的としたWebサイトです。
本サイトは保守性・拡張性を高めるため、Vite + React を用いてコンポーネント化され再構築されました。

## ✨ コンセプト & デザイン

- **Concept**: 「変われる。あなたも、何度でも。」
    - 才能や実績を誇示するのではなく、等身大のストーリーで「私も変われるかも」という希望を届けます。
- **Design Theme**: Natural & Honest（ナチュラル・誠実）
    - 白とオフホワイトを基調に、落ち着いたブルー（#5a8ab8）をアクセントに使用。
    - 余白を多めに取り、読み物として心地よいスクロール構成。
    - フォントは明朝体（Noto Serif JP）とゴシック体（Zen Kaku Gothic New）を組み合わせ、誠実さと親しみやすさを両立。

## 🚀 起動方法（ローカル環境）

Node.js がインストールされている環境で、以下のコマンドを実行して開発サーバーを起動してください。

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

起動後、表示されるローカルURL（例: `http://localhost:5173/`）をブラウザで開いて確認できます。
本番用のビルドを行いたい場合は `npm run build` を使用してください。

## 📁 ディレクトリ構成

保守性を高めるため、責務やUIごとにReactコンポーネントを分割しています。各コードには目的や役割をコメントで記載しています。

```
.
├── public/                 # 静的アセット（画像ファイル等）
│   ├── hero_portrait.webp
│   ├── story_before_after.webp
│   └── profile_casual.webp
├── src/                    # ソースコード
│   ├── components/         # Reactコンポーネント群
│   │   ├── Header.jsx      # ナビゲーション・ヘッダー
│   │   ├── Hero.jsx        # ファーストビュー
│   │   ├── Story.jsx       # 体験談セクション
│   │   ├── Profile.jsx     # プロフィール
│   │   ├── Career.jsx      # 実績・資格セクション
│   │   ├── SNS.jsx         # Instagram等への導線
│   │   └── Footer.jsx      # フッター
│   ├── styles/             # カスケーディングスタイルシート
│   │   └── style.css       # 全体のデザイン定義
│   ├── App.jsx             # メインコンポーネント（アニメーション等の制御）
│   └── main.jsx            # アプリケーションのエントリーポイント
├── index.html              # HTMLの雛形（Viteのエントリポイント）
├── package.json            # パッケージ管理とスクリプト定義
└── vite.config.js          # Viteのビルド設定
```

## 🎨 画像のカスタマイズ

画像を差し替える場合は、`public` フォルダ内にある以下のファイルを上書きしてください。

1. **`hero_portrait.webp`**:
   - ヒーローセクション用。自然光の中で撮影された、明るい笑顔の写真やトレーニング風景等。
2. **`story_before_after.webp`**:
   - ストーリーセクション用。過去の自分と現在の自分を比較する画像、または象徴的なエピソード画像等。
3. **`profile_casual.webp`**:
   - プロフィールセクション用。ジャージや私服など、人柄が伝わるカジュアルな写真。

## 🛠 技術スタック

- **React 18**: UI構築用ライブラリ
- **Vite**: 高速な開発環境・ビルドツール
- **CSS3**: カスタムプロパティ（変数）、Flexbox/Gridを使ったレスポンシブデザイン
- **JavaScript (ES6+)**: `IntersectionObserver` などの最新APIによるスクロールアニメーション
- **Google Fonts**: Noto Serif JP, Zen Kaku Gothic New

## 📄 ライセンス

このプロジェクトはポートフォリオとして自由に使用・改変可能です。
